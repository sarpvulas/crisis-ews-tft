# Reproducing the results with Docker

This guide lets a third party (e.g. the examiner) run the dissertation's
headline experiments from a single Docker image — no Python setup, no Bloomberg
access, and no GPU required. Mock surrogate datasets are included in the
repository, so the run is self-contained.

The container pins the same Python (3.11) and dependency floors used on the KCL
CREATE cluster. On the real data, results match the cluster runs up to
seed-level noise; on the included mock data, expect larger deviations (the
protocol and the direction of the comparisons are what replicates).

---

## 1. What gets reproduced

`scripts/run_experiment.py` trains a model on the leak-free, embargoed S&P 500
**dd10** Task-B dataset (or the nine-market panel) and writes a metrics JSON
(PR-AUC, ROC-AUC, ECE, Brier) to `results/`.

The two headline claims:

| Study | Result (macro test PR-AUC, ~30 seeds on GPU) |
|---|---|
| **Single-market** | **AF 0.487 vs vanilla TFT 0.459**; AF has lower Brier in **all six** folds (best calibration). Tuned trees (RF 0.354 / XGB 0.340 / HistGB 0.333) trail the deep models. |
| **Nine-market panel** | **AFv2 0.385 vs XGBoost 0.373** PR-AUC (best Brier); deep ≈ marginally ahead of trees. |

> **Seeds:** the dissertation averages ~30 seeds (GPU). A single CPU seed (below)
> reproduces the **direction** — AF ≥ vanilla, strongest on the severe COVID and
> China-2015 folds — not the exact multi-seed means.

The datasets are committed under `data/mock/`:
`taskb_spx_bbg_onset_trough_rp252_dd10_emb63_6f/` (single-market, six folds) and
`panel_dd10_rp252/panel.parquet` (nine-market panel).

> **Note:** these are **mock datasets** — synthetic surrogates of my processed
> feature data, generated by heavy seeded perturbation because Bloomberg's
> licence does not permit redistributing the original values. Feature columns
> carry autocorrelated AR(1) noise at 20% of each column's std; labels,
> targets, dates and the split/embargo structure match the real task (see
> *Data & licensing* in the README). Metrics obtained on the mock data
> demonstrate the protocol and the direction of the comparisons, not the
> exact dissertation numbers, which were produced on the real data.

## 2. Prerequisites

- **Docker Desktop** (Windows/macOS) or **Docker Engine** (Linux) with the
  `docker compose` v2 plugin. On Windows this installs the WSL2 backend.
- ~3 GB free disk for the CPU image; a few minutes to build.
- A GPU is **optional** — the default image is CPU-only and reproduces the same
  numbers, just slower.

```bash
docker --version
docker compose version
```

---

## 3. Build the image

From the repository root:

```bash
docker compose build train            # CPU image, ~1–2 min after base pulls
docker compose run --rm train --help  # sanity-check the CLI
```

---

## 4. Single-market reproduction

**(a) One command — the AF recipe (recommended model):**

```bash
docker compose run --rm train \
  --model ra-tft --task B --seed 0 --epochs 40 \
  --use-aux 1 --lambda-aux 0.5 --loss focal --focal-gamma 2 --pos-weight 3.4 \
  --posthoc-calibrate platt \
  --data-dir data/mock/taskb_spx_bbg_onset_trough_rp252_dd10_emb63_6f \
  --results-dir results --checkpoint-dir checkpoints --device auto
```

Drop the `--use-aux … --pos-weight 3.4` flags for the **vanilla TFT** baseline.

**(b) Full headline — AF vs vanilla across all six folds (one script):**

```bash
bash scripts/reproduce.sh             # ~12 CPU trainings; prints a PR-AUC table
EPOCHS=10 bash scripts/reproduce.sh   # faster smoke version
```

It loops the six crisis folds (GFC, Eurozone, China-2015, Q4-2018, COVID, 2022),
runs vanilla and AF at seed 0, and prints per-fold and macro test PR-AUC. Expect
AF ≥ vanilla overall, with the largest gains on COVID and China-2015.

**(c) Tree / sequence baselines** — swap the model:

```bash
docker compose run --rm train --model xgboost --task B --seed 0 \
  --data-dir data/mock/taskb_spx_bbg_onset_trough_rp252_dd10_emb63_6f \
  --results-dir results --checkpoint-dir checkpoints --device auto
# also: plessis-rf (random forest), histgb, lstm, logistic
```

---

## 5. Panel reproduction (AFv2)

```bash
docker compose run --rm train \
  --model ra-tft --task B --seed 0 --epochs 60 \
  --state-size 128 --hidden-size 128 --lr 5e-4 \
  --use-aux 1 --lambda-aux 0.5 --loss focal --focal-gamma 2 --pos-weight 2.5 \
  --panel-path data/mock/panel_dd10_rp252/panel.parquet \
  --panel-train-end 2015-12-31 --panel-val-end 2018-12-31 \
  --panel-per-market-norm 1 --posthoc-calibrate platt \
  --results-dir results --checkpoint-dir checkpoints --device auto
```

---

## 6. GPU (optional, faster)

With an NVIDIA GPU + container toolkit:

```bash
docker compose -f docker-compose.yml -f docker-compose.gpu.yml build train
docker compose -f docker-compose.yml -f docker-compose.gpu.yml run --rm train <args> --device cuda
```

## 7. Full multi-seed experiments (HPC)

The exact dissertation numbers (≈30 seeds, six folds, significance tests) were
produced by the Slurm array jobs in `scripts/job_*.sh` on the KCL CREATE cluster
(e.g. `job_conf_6fold.sh`, `job_tree_tune.sh`, `job_panel_wf.sh`). Figures are
regenerated with `python scripts/make_figures.py`.

---

## 8. Notes

- Results, checkpoints, and outputs are bind-mounted, so they persist on the host
  under `results/` and `checkpoints/` after each container exits.
- The included parquets under `data/mock/` are mock surrogates, not Bloomberg
  data (see *Data & licensing* in the README). The raw Bloomberg pull is not
  included; the pipeline in `data/pipelines/` regenerates the real datasets
  from a licensed source.
- On Windows PowerShell, run the `docker compose` commands as-is; only
  `bash scripts/reproduce.sh` needs a bash shell (Git Bash or WSL).
